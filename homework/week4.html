Week 4 Homework

Forks, pipes, colliders, and the paradoxes they create

These exercises go with the Week 4 lecture. Part A checks your understanding of the ideas. Parts B and C are problems to work through with pen and paper. Part D asks you to make the paradoxes happen yourself in R. Part E is about your own project. Part F is an optional R challenge.

A few ground rules:

  • Draw the DAG first. Almost every question this week gets easier once you have the picture in front of you. Pen and paper is fine. So is dagitty.net.
  • Show your work. Name every path between X and Y and say whether it is open or closed. A correct answer with no paths is worth less than a wrong answer with clear reasoning.
  • Write in plain language. If you can’t explain it to a friend who missed the lecture, you haven’t finished understanding it yet.
  • Problems marked ★ are harder. Give them a real try, but don’t get stuck on them.

A reminder of the words we use. Holding Z fixed, controlling for Z, adjusting for Z and conditioning on Z all mean the same thing. A path is open if association can flow along it, and closed if it can’t.

Part C: Should I control for it?

You can type each DAG below into dagitty.net to check your answers. But do each question by hand first.

C1. Remittances and school results. We want the effect of a household receiving remittances on a child’s school results. Assume this DAG:

dag {
  District -> Wealth
  District -> Results
  Wealth -> Remittances
  Wealth -> Results
  Remittances -> Results
  Remittances -> Tuition
  Tuition -> Results
  Remittances -> Boarding
  Results -> Boarding
}

Wealth is the household’s wealth before anyone went abroad. Tuition is money spent on tuition classes. Boarding means the child moved to a boarding school in Kathmandu, which needs money and good results.

  1. List every path between Remittances and Results. There are five.
  2. For each path: is it a causal path or a back door? Is it open or closed right now? Name each fork, pipe and collider along the way.
  3. For each of District, Wealth, Tuition and Boarding, say whether you should control for it to get the total effect of remittances. Give a reason for each.
  4. What is the smallest set of variables that closes every back door?
  5. A classmate controls for Wealth and Boarding. What goes wrong?
  6. What would you control for if you wanted only the direct effect, not the part that works through tuition?

C2. ★ A collider that comes first. We want the effect of taking Lok Sewa coaching classes on passing the Lok Sewa exam. Assume this DAG. Motivation is not measured.

dag {
  Wealth -> Coaching
  Wealth -> Kathmandu
  Motivation -> Kathmandu
  Motivation -> Passed
  Coaching -> Passed
}

Kathmandu means the person lives in Kathmandu. Richer people and more motivated people are both more likely to move there.

  1. List both paths between Coaching and Passed. Which one is open?
  2. A colleague says: “Where someone lives was decided before they took coaching, so it is safe to control for it.” Is she right? What happens if you control for Kathmandu alone?
  3. Suppose you have already controlled for Kathmandu, and your supervisor insists it stays in the model. What else could you control for to fix the problem?
  4. Which rule of the back-door rule does this question illustrate?

C3. A paradox inside a paradox. Go back to the Berkeley admissions example, with ability added:

dag {
  Sex -> Department
  Department -> Admitted
  Sex -> Admitted
  Ability -> Department
  Ability -> Admitted
}
  1. If we want the total effect of sex on admission, what should we control for?
  2. We want the direct effect (do committees treat women differently?), so we hold department fixed. Write down the path this opens. Which part of it is the collider?
  3. Why can’t we fix this by controlling for something else, if ability is not measured?
  4. Suppose we could measure ability. What would we control for to get the direct effect?

Part D: Make the paradoxes yourself

In this part you build the made-up worlds from lecture in R. Because you make the world, you know the true answer, so you can see exactly when a method goes wrong. Use cor() and lm() for quick answers. Copy the code exactly, including set.seed(), so your numbers match your classmates’.

D1. The fork: marriage and happiness. In this world, urban people marry later and are happier, but age at marriage has no effect on happiness.

set.seed(116)
n <- 500
urban <- rbinom(n, 1, 0.5)
age <- 25 + 3 * rnorm(n, 2 * urban - 1)
happiness <- 5 + 1.5 * rnorm(n, 2 * urban - 1)
  1. Find the correlation between age and happiness for everyone.
  2. Find the correlation separately for urban and for rural people.
  3. Fit lm(happiness ~ age) and lm(happiness ~ age + urban). What is the coefficient on age in each? Which one matches the truth?
  4. In one sentence: which path did adding urban close?

D2. The pipe: the anti-fungal treatment. In this world, the treatment lowers the chance of fungus, and fungus slows growth. The treatment does nothing else.

set.seed(71)
n <- 400
treated <- rep(c(0, 1), each = n / 2)
fungus <- rbinom(n, 1, ifelse(treated == 1, 0.1, 0.5))
growth <- rnorm(n, 5 - 3 * fungus, 1)
  1. Compare the average growth of treated and untreated plants.
  2. Fit lm(growth ~ treated) and lm(growth ~ treated + fungus). What is the coefficient on treated in each?
  3. Which model would you show a farmer who asks “should I buy this treatment?” Why?

D3. The collider: grant proposals. Newsworthiness and trustworthiness are unrelated. Reviewers fund proposals with the highest combined score.

set.seed(1914)
n <- 200
newsworthy <- rnorm(n)
trustworthy <- rnorm(n)
score <- newsworthy + trustworthy
funded <- score >= quantile(score, 0.9)   # top 10% get funded
  1. Find the correlation between newsworthiness and trustworthiness for all 200 proposals, and for the funded ones only.
  2. Using the same data, change the cutoff so the top 50% get funded. What is the correlation among funded proposals now? What happens as funding gets more selective?
  3. Now fund the top 10% on newsworthiness alone. What is the correlation among funded proposals? Why is it so different from (a)?
  4. Selecting the sample is one way to hold Z fixed. Adding Z to a regression is another. Fit lm(trustworthy ~ newsworthy + funded) on all 200 proposals. What is the coefficient on newsworthy? What does this tell you about putting a collider in a regression?

Part F: R challenge (optional)

F1. A proxy for a confounder. Simulate a world where wealth causes both phones and births, and phones have no effect on births. Then try controlling for wealth itself, for a good proxy, and for a poor proxy.

set.seed(42)
n <- 1000
wealth <- rnorm(n)
phones <- wealth + rnorm(n, 0, 0.5)
births <- -wealth + rnorm(n, 0, 0.5)
proxy_good <- wealth + rnorm(n, 0, 0.3)
proxy_bad <- wealth + rnorm(n, 0, 1)

Report the coefficient on phones in four models: no control, + wealth, + proxy_good, + proxy_bad. Explain the pattern using the word descendant.

F2. Berkson’s paradox. Two diseases each affect 10% of people and are completely unrelated. Either one makes hospital admission much more likely.

set.seed(2020)
n <- 10000
d1 <- rbinom(n, 1, 0.1)
d2 <- rbinom(n, 1, 0.1)
hospital <- rbinom(n, 1, pmin(1, 0.02 + 0.5 * d1 + 0.5 * d2)) == 1
  1. Find the correlation between d1 and d2 for everyone and for hospital patients only.
  2. Among hospital patients, what share of people with disease 1 also have disease 2? What share of people without disease 1 have disease 2?
  3. Explain why a doctor who only sees hospital patients might wrongly think disease 1 protects against disease 2.

F3. ★ Simulate the Lok Sewa world from C2 and check your answers. Here the true effect of coaching on the exam score is 0.3.

set.seed(5)

motivation <- rnorm(n)
kathmandu <- wealth + motivation + rnorm(n) > 0
coaching <- wealth + rnorm(n)

Compare the coefficient on coaching with no controls, with kathmandu, and with kathmandu + wealth. Which models get close to 0.3? Does this match your answer to C2?
