Randomness has patterns

Problem: we want to understand how the admissions process works at a university.

Population: This isn’t about one individual case but rather a group of cases

  • “Applications to this university last year”
  • “Applications to this university in the last ten years”
  • “Applications to all state-run universities in this country last year”

Variation: These cases are different from each other in ways that interest us

  • “Exam results”
  • “Family wealth”
  • “Gender”
  • “Department”

Randomness: Reality is messy, and we’ll never predict admission perfectly. But, randomness has patterns. We can describe how it was generated.

  • If I flip a coin 1 time, I can’t say what will happen.
  • If I flip a coin 1000 times, I can say a lot more.
  • Random individuals → Predictable populations

Probability distributions: talking about numbers differently

Note

  • We talk about probability distributions all the time: “He’s probably about 40, but he could be quite a bit older”.
  • Here, we’re just visualizing that kind of description over the range of all possible values.

Uninformed I have no idea. He could be between 0 and 100 and I don’t think any possibility is more likely than any other.

Weakly informed He seems like he’s about 40, but I could be very wrong about that. Anything between 20 and 60 seems plausible and even more extreme values are possible.

Strongly informed I’m quite certain that he’s forty or relatively close to it.

Domain-specific distributions I’m relatively certain he’s between 30 and 50, but I have really no idea where in that range he lands. Older or younger than that seems unlikely, though.

Two kinds of distributions

Distributions of data

How a quantity varies across cases.

  • Heights of the adults in a village
  • Prices of houses sold last year
  • Ages of everyone in Nepal

Distributions of belief

How plausible each value of a parameter is.

  • The mayor’s share of the vote
  • The age of the man in the photo
  • How much heavier taller people are

Same shapes, same vocabulary, same math. Today we start with the first kind and end with the second.

Population of Nepal

  • Census data collected by anthropologist Nancy Howell in the late 1960s among the !Kung San of the Kalahari.
  • 352 adults (18+).
  • Height (cm), weight (kg), age, sex.

Describing a distribution

  • Center: where is a typical value? (mean)
  • Spread: how far is a typical case from the center? (standard deviation)
  • Shape: one hump or two? Symmetric, or a long tail?

The Normal distribution

  • The blue curve is a Normal distribution with
    • mean = 154.6
    • SD = 7.7
  • Two numbers describe the whole shape.
  • Real data is never perfectly Normal, but many things are close.

\[ \text{height} \sim \text{Normal}(\mu = 154.6,\ \sigma = 7.7) \]

The 68–95–99.7 rule

  • For a Normal distribution, about 68% of cases fall within 1 SD of the mean, 95% within 2 SD.
  • Check: 65% of !Kung adults are within 1 SD of the average height, and 96% within 2 SD.

server <- function(input, output, session) {
  draws <- reactiveVal(numeric(0))

  observeEvent(input$axis_modal, {
    showModal(
      modalDialog(
        title = "Axis limits",
        checkboxInput(
          "manual_xlim",
          "Manual x-axis range",
          value = isTRUE(input$manual_xlim)
        ),
        conditionalPanel(
          condition = "input.manual_xlim === true",
          numericInput("xlim_min", "x-min", value = input$xlim_min %||% NA),
          numericInput("xlim_max", "x-max", value = input$xlim_max %||% NA)
        ),
        checkboxInput(
          "manual_ylim",
          "Manual y-axis range",
          value = isTRUE(input$manual_ylim)
        ),
        conditionalPanel(
          condition = "input.manual_ylim === true",
          numericInput("ylim_min", "y-min", value = input$ylim_min %||% NA),
          numericInput("ylim_max", "y-max", value = input$ylim_max %||% NA)
        ),
        footer = tagList(
          tags$button(
            type = "button",
            class = "btn btn-secondary",
            `data-bs-dismiss` = "modal",
            style = "padding-left:10px; padding-right:10px;",
            "Close"
          )
        )
      )
    )
  })

  observeEvent(
    list(
      input$trialCount,
      input$successRate,
      input$bern_p,
      input$distType,
      input$mean,
      input$sd,
      input$umin,
      input$umax,
      input$exp_rate,
      input$poisson_lambda,
      input$beta_alpha,
      input$beta_beta,
      input$gamma_shape,
      input$gamma_rate,
      input$manual_xlim,
      input$xlim_min,
      input$xlim_max,
      input$manual_ylim,
      input$ylim_min,
      input$ylim_max
    ),
    {
      draws(numeric(0))
    },
    ignoreInit = TRUE
  )

  # helper: sanitize a positive numeric input
  safe_pos <- function(x, fallback = 1) {
    if (is.null(x) || !is.finite(x) || x <= 0) fallback else x
  }
  safe_nonneg <- function(x, fallback = 1) {
    if (is.null(x) || !is.finite(x) || x < 0) fallback else x
  }

  add_draws <- function(k) {
    new <- switch(
      input$distType,
      "Bernoulli" = rbinom(k, size = 1, prob = input$bern_p / 100),
      "Binomial" = rbinom(
        k,
        size = input$trialCount,
        prob = input$successRate / 100
      ),
      "Normal" = rnorm(k, mean = input$mean, sd = safe_pos(input$sd)),
      "Uniform" = runif(k, min = input$umin, max = input$umax),
      "Exponential" = rexp(k, rate = safe_pos(input$exp_rate)),
      "Poisson" = rpois(k, lambda = safe_nonneg(input$poisson_lambda)),
      "Beta" = rbeta(
        k,
        shape1 = safe_pos(input$beta_alpha),
        shape2 = safe_pos(input$beta_beta)
      ),
      "Gamma" = rgamma(
        k,
        shape = safe_pos(input$gamma_shape),
        rate = safe_pos(input$gamma_rate)
      ),
      numeric(0)
    )
    draws(c(draws(), new))
  }

  observeEvent(input$draw1, add_draws(1))
  observeEvent(input$draw10, add_draws(10))
  observeEvent(input$draw100, add_draws(100))
  observeEvent(input$draw1000, add_draws(1000))
  observeEvent(input$reset, {
    # clear simulated draws
    draws(numeric(0))

    # reset UI controls to their defaults (match UI definitions)
    updateSelectizeInput(session, "distType", selected = "Binomial")

    updateSliderInput(session, "bern_p", value = 50)

    updateSliderInput(session, "successRate", value = 50)
    updateNumericInput(session, "trialCount", value = 10)

    updateNumericInput(session, "mean", value = 0)
    updateNumericInput(session, "sd", value = 1)

    updateNumericInput(session, "umin", value = 0)
    updateNumericInput(session, "umax", value = 1)

    updateNumericInput(session, "exp_rate", value = 1)
    updateNumericInput(session, "poisson_lambda", value = 1)

    updateNumericInput(session, "beta_alpha", value = 2)
    updateNumericInput(session, "beta_beta", value = 2)

    updateNumericInput(session, "gamma_shape", value = 2)
    updateNumericInput(session, "gamma_rate", value = 1)

    updateCheckboxInput(session, "manual_xlim", value = FALSE)
    updateNumericInput(session, "xlim_min", value = NA)
    updateNumericInput(session, "xlim_max", value = NA)

    updateCheckboxInput(session, "manual_ylim", value = FALSE)
    updateNumericInput(session, "ylim_min", value = NA)
    updateNumericInput(session, "ylim_max", value = NA)
  })

  output$plot <- renderGirafe({
    sim <- draws()

    # ---------- helpers ----------
    empty_plot <- function() girafe(ggplot(), width_svg = 12, height_svg = 8)

    # common theme
    base_theme <- theme_minimal() +
      theme(plot.margin = margin(10, 30, 30, 10))

    # ---------- spec builder ----------
    get_dist_spec <- function(sim) {
      dist <- input$distType

      # ---- BERNOULLI ----
      if (dist == "Bernoulli") {
        p <- input$bern_p / 100
        theory <- data.frame(
          x = 0:1,
          prob = dbinom(0:1, 1, p)
        )

        list(
          type = "discrete",
          theory = theory,
          xlim = c(0, 1),
          ymax = max(theory$prob),
          xlabel = "Outcome (0/1)",
          ylabel = "Probability",
          tooltip_theory = function(df) {
            paste0(
              "Outcome = ",
              df$x,
              "<br>Probability = ",
              round(df$prob, 4)
            )
          }
        )
      } else if (dist == "Binomial") {
        # ---- BINOMIAL ----
        n <- input$trialCount
        p <- input$successRate / 100

        theory <- data.frame(
          x = 0:n,
          prob = dbinom(0:n, n, p)
        )

        list(
          type = "discrete",
          theory = theory,
          xlim = c(0, n),
          ymax = max(theory$prob),
          xlabel = "Number of successes",
          ylabel = "Probability",
          tooltip_theory = function(df) {
            paste0(
              "Success = ",
              df$x,
              " out of ",
              n,
              "<br>Probability = ",
              round(df$prob, 4)
            )
          }
        )
      } else if (dist == "Normal") {
        # ---- NORMAL ----
        mu <- input$mean
        sd <- safe_pos(input$sd)

        x_min <- mu - 4 * sd
        x_max <- mu + 4 * sd

        xs <- seq(x_min, x_max, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dnorm(xs, mu, sd)
        )

        list(
          dist = "Normal",
          params = list(mu = mu, sd = sd),
          type = "continuous",
          theory = theory,
          xlim = c(x_min, x_max),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else if (dist == "Uniform") {
        # ---- UNIFORM ----
        a <- input$umin
        b <- input$umax
        if (b <= a) {
          return(NULL)
        }

        xs <- seq(a, b, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dunif(xs, a, b)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(a, b),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density",
          expand_mult = c(0, .85)
        )
      } else if (dist == "Exponential") {
        # ---- EXPONENTIAL ----
        rate <- safe_pos(input$exp_rate)

        x_min <- 0
        x_max <- qexp(.999, rate)

        xs <- seq(x_min, x_max, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dexp(xs, rate)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(x_min, x_max),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else if (dist == "Poisson") {
        # ---- POISSON ----
        lambda <- safe_nonneg(input$poisson_lambda)

        x_max_theory <- ceiling(qpois(.999, lambda))
        x_max_sim <- if (length(sim)) {
          max(ceiling(sim), x_max_theory)
        } else {
          x_max_theory
        }
        xs <- 0:x_max_sim

        theory <- data.frame(
          x = xs,
          prob = dpois(xs, lambda)
        )

        list(
          type = "discrete",
          theory = theory,
          xlim = c(0, x_max_sim),
          ymax = max(theory$prob),
          xlabel = "k",
          ylabel = "Probability",
          tooltip_theory = function(df) {
            paste0("k = ", df$x, "<br>Probability = ", round(df$prob, 4))
          }
        )
      } else if (dist == "Beta") {
        # ---- BETA ----
        a <- safe_pos(input$beta_alpha)
        b <- safe_pos(input$beta_beta)

        xs <- seq(0, 1, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dbeta(xs, a, b)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(0, 1),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else if (dist == "Gamma") {
        # ---- GAMMA ----
        shape <- safe_pos(input$gamma_shape)
        rate <- safe_pos(input$gamma_rate)

        x_min <- 0
        x_max <- qgamma(.999, shape, rate)

        xs <- seq(x_min, x_max, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dgamma(xs, shape, rate)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(x_min, x_max),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else {
        NULL
      }
    }

    # ---------- build plot ----------
    spec <- get_dist_spec(sim)
    if (is.null(spec)) {
      return(empty_plot())
    }

    apply_manual_xlim <- function(spec) {
      if (!isTRUE(input$manual_xlim)) {
        return(spec)
      }

      xmin <- input$xlim_min
      xmax <- input$xlim_max

      if (
        is.null(xmin) ||
          is.null(xmax) ||
          !is.finite(xmin) ||
          !is.finite(xmax) ||
          xmin >= xmax
      ) {
        return(spec)
      }

      spec$xlim <- c(xmin, xmax)

      if (spec$type == "continuous") {
        if (identical(spec$dist, "Normal")) {
          mu <- spec$params$mu
          sd <- spec$params$sd
          xs <- seq(xmin, xmax, length.out = 400)
          spec$theory <- data.frame(
            x = xs,
            density = dnorm(xs, mu, sd)
          )
        } else {
          spec$theory <- spec$theory[
            spec$theory$x >= xmin & spec$theory$x <= xmax,
            ,
            drop = FALSE
          ]
        }
        ymax <- max(spec$theory$density, na.rm = TRUE)
        if (is.finite(ymax)) {
          spec$ymax <- ymax
        }
      } else {
        spec$theory <- spec$theory[
          spec$theory$x >= xmin & spec$theory$x <= xmax,
          ,
          drop = FALSE
        ]
        ymax <- max(spec$theory$prob, na.rm = TRUE)
        if (is.finite(ymax)) {
          spec$ymax <- ymax
        }
      }

      spec
    }

    spec <- apply_manual_xlim(spec)

    apply_manual_ylim <- function(spec) {
      if (!isTRUE(input$manual_ylim)) {
        return(spec)
      }

      ymin <- input$ylim_min
      ymax <- input$ylim_max

      if (
        is.null(ymin) ||
          is.null(ymax) ||
          !is.finite(ymin) ||
          !is.finite(ymax) ||
          ymin >= ymax
      ) {
        return(spec)
      }

      spec$ylim <- c(ymin, ymax)
      spec
    }

    spec <- apply_manual_ylim(spec)

    g <- ggplot()

    # ---- simulated layer ----
    if (spec$type == "continuous") {
      if (length(sim) > 0) {
        g <- g +
          geom_histogram_interactive(
            data = data.frame(x = sim),
            aes(
              x = x,
              y = after_stat(density),
              tooltip = paste0("Count: ", after_stat(count)),
              data_id = after_stat(x)
            ),
            bins = 40,
            boundary = spec$xlim[1],
            fill = "steelblue",
            alpha = .6,
            color = "white",
            linewidth = .4
          )
      }

      g <- g +
        geom_line(
          data = spec$theory,
          aes(x = x, y = density),
          linewidth = 1
        )
    } else if (spec$type == "discrete") {
      # sim df
      df_sim <- if (length(sim) == 0) {
        data.frame(x = integer(), prob = numeric(), count = integer())
      } else {
        tab <- table(sim)
        data.frame(
          x = as.integer(names(tab)),
          count = as.integer(tab),
          prob = as.integer(tab) / sum(tab)
        )
      }

      g <- g +
        geom_col_interactive(
          data = df_sim,
          aes(
            x = x,
            y = prob,
            tooltip = paste0(

Standardized values (z-scores)

A !Kung man is 165 cm tall and weighs 58 kg. Is he more unusually tall or more unusually heavy?

  • We can’t compare centimeters to kilograms.
  • But we can ask of each: how many standard deviations from average is this?

\[ z = \frac{x - \text{mean}}{\text{SD}} \]

  • Height: (165 − 154.6) / 7.7 = 1.34
  • Weight: (58 − 45.0) / 6.5 = 2.01
  • He is more unusually heavy than he is tall.

Same data, new ruler

  • The shape doesn’t change at all. Only the labels on the axis.
  • The mean becomes 0. The standard deviation becomes 1.
  • The units disappear: a z-score is measured in “standard deviations”.

Reading z-scores

z Meaning
0 exactly average
±1 ordinary
±2 unusual (about 1 in 20)
±3 rare (about 1 in 370)

In R:

howell |>
  mutate(
    z_height = (height - mean(height)) / sd(height),
    z_weight = (weight - mean(weight)) / sd(weight)
  )
  • z-scores let us compare things measured on completely different scales: exam marks out of 50 vs. out of 100, rupees vs. dollars, cm vs. kg.

Correlation

  • Taller people tend to be heavier. But how strongly do they go together?

Standardize both variables

Correlation is average agreement

\[ r = \frac{1}{n-1} \sum_{i=1}^{n} z_{\text{height},i} \times z_{\text{weight},i} \]

  • Each person “votes”:
    • Same side of average on both → positive vote
    • Opposite sides → negative vote
  • r is the average vote.
cor(howell$height, howell$weight)
[1] 0.7547479
  • r is always between −1 and +1.
  • r has no units.
  • Standardizing changes nothing: r in cm/kg = r in z-scores.

What does r look like?

  • Our height and weight: r = 0.75. A strong relationship, but far from perfect.

What correlation misses

  • r only measures straight-line agreement.
  • Always plot your data before trusting a single number.

Regression: our first coefficient

In z-space, both variables have mean 0, so a line through the middle of the cloud needs only one parameter: its slope, β.

\[ z_{\text{weight}} = \beta \times z_{\text{height}} \]

  • Which line describes the data best?

The best line

  • The red lines are the errors: how far each person is from the line.
  • The best line makes the errors as small as possible overall.
  • With standardized data and one predictor, the best β is exactly the correlation: β = r = 0.75.

Reading the coefficient

  • In z-scores: β = 0.75
    • “An adult 1 SD taller than average is, on average, 0.75 SD heavier.”
  • Back in real units: β × SDweight / SDheight
    • 0.75 × 6.5 / 7.7 = 0.63 kg per cm
    • “Each extra centimeter of height goes with about 0.63 kg more weight.”
coef(lm(weight ~ height, data = howell))
(Intercept)      height 
 -52.316178    0.629421

β is a parameter, so it has a distribution

  • Just like the mayor’s popularity last week: prior × likelihood → posterior.
  • With 20 people we’re unsure about β. With 352, much less so.

Part 1: Summary

  • Distributions: describe numbers by their center, spread, and shape, not just a single value.
  • z-scores: how many SDs from the average. One ruler for everything.
  • Correlation (r): the average agreement of two z-scores, from −1 to +1.
  • Regression coefficient (β): the slope of the best line. With standardized data and one predictor, β = r.
  • β is a parameter: we can have a prior and a posterior distribution for it.
