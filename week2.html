Data Lunch: Week 2

Describing uncertainty

The three parts of statistical questions

  • Population
  • Variation
  • Randomness

Random individuals → Predictable populations

  • If I flip a coin 1 time, I can’t say what will happen.
  • If I flip a coin 1000 times, I can say a lot more.

Statistical models

Randomness has patterns

Goals this week

  • Get more specific about “beliefs”
  • Learn how to use Bayes Theorem
    • Priors and posteriors
    • Likelihood
  • Design a real analysis

Parameters: What is a “belief”?

  • Beliefs about what?
    • “parameters”: unknown numerical quantities in the world
    • “estimand”: what we want to find out (often a parameter)
  • Refined Definition:
    • P(belief): P(belief about the possible values of a parameter)
    • Shorthand: P(params) or P(Θ)

Parameters: Examples

A parameter is a numerical fact about the world that we don’t know (but want to find out)

  • The average height of adults in Pokhara
  • The number of cars driven in Kathmandu on a typical Saturday
  • The average exam results in a particular school
  • The difference between men’s and women’s salaries
  • The effect of socioeconomic status on college admissions
  • The effect of education level on moral judgments

Parameters: Probability distributions

Note

  • We talk about probability distributions all the time: “He’s probably about 50, but he could be quite a bit older”.
  • Here, we’re just visualizing that kind of description over the range of all possible values.

Uninformed I have no idea. He could be between 0 and 100 and I don’t think any possibility is more likely than any other.

Weakly informed He seems like he’s about 50, but I could be very wrong about that. Anything between 30 and 70 seems plausible and even more extreme values are possible.

Strongly informed I’m quite certain that he’s fifty or relatively close to it.

Domain-specific distributions I’m relatively certain he’s between 40 and 60, but I have really no idea where in that range he lands. Older or younger than that seems unlikely, though.

Practical: Who will win the election?

  • Last election: the current candidate got 60% of the votes.
  • We have the resources to conduct a survey.
  • (Many non-statistical problems to solve when we design a survey.)
  • What do we need to provide a meaningful statistical answer?

Practical: Bayes Theorem

\[ \color{green}{P(\text{belief} \mid \text{data})} = \frac{ \color{#1b91ff}{P(\text{data} \mid \text{belief})} \;\color{#ff2c2d}{P(\text{belief})} }{ \color{#999}{P(\text{data})} } \]

  • P(belief): prior
  • P(belief | data): posterior
  • P(data | belief): likelihood
  • P(data): marginal likelihood (not interesting)

prior ⨉ likelihood → posterior

Priors and Posteriors: Updating

P(belief) → P(belief | data)

Priors and Posteriors: Defining a distribution

Likelihood: Probability in the World

Probability isn’t just in our heads. Sometimes, it’s generated by a process in the world.

Likelihood: What it is

  • For priors and posteriors, randomness is about our uncertainty (a subjective experience).
  • For likelihood, randomness is a characteristic of the world.
  • Our job is to describe how patterns of variation (including randomness) occur.

Likelihood: Building Models

  • From Bayes theorem, we know that likelihood is: P( data | parameters )
  • But what does this mean?

Survey Results!

Let’s say we surveyed 15 people and 4 said that they will vote for the current mayor.

  • Given a particular parameter value, how likely is the data we saw?
    • If our parameter is actually 50%, what are the chances of seeing 4 out of 15?
    • If our parameter is actually 30%, what are the chances of seeing 4 out of 15?
    • If our parameter is actually 80%, what are the chances of seeing 4 out of 15?

These are questions that any calculator can answer.

server <- function(input, output, session) {
  draws <- reactiveVal(numeric(0))

  observeEvent(
    list(
      input$trialCount,
      input$successRate,
      input$bern_p,
      input$distType,
      input$mean,
      input$sd,
      input$umin,
      input$umax,
      input$exp_rate,
      input$poisson_lambda,
      input$beta_alpha,
      input$beta_beta,
      input$gamma_shape,
      input$gamma_rate
    ),
    {
      draws(numeric(0))
    },
    ignoreInit = TRUE
  )

  # helper: sanitize a positive numeric input
  safe_pos <- function(x, fallback = 1) {
    if (is.null(x) || !is.finite(x) || x <= 0) fallback else x
  }
  safe_nonneg <- function(x, fallback = 1) {
    if (is.null(x) || !is.finite(x) || x < 0) fallback else x
  }

  add_draws <- function(k) {
    new <- switch(
      input$distType,
      "Bernoulli" = rbinom(k, size = 1, prob = input$bern_p / 100),
      "Binomial" = rbinom(
        k,
        size = input$trialCount,
        prob = input$successRate / 100
      ),
      "Normal" = rnorm(k, mean = input$mean, sd = safe_pos(input$sd)),
      "Uniform" = runif(k, min = input$umin, max = input$umax),
      "Exponential" = rexp(k, rate = safe_pos(input$exp_rate)),
      "Poisson" = rpois(k, lambda = safe_nonneg(input$poisson_lambda)),
      "Beta" = rbeta(
        k,
        shape1 = safe_pos(input$beta_alpha),
        shape2 = safe_pos(input$beta_beta)
      ),
      "Gamma" = rgamma(
        k,
        shape = safe_pos(input$gamma_shape),
        rate = safe_pos(input$gamma_rate)
      ),
      numeric(0)
    )
    draws(c(draws(), new))
  }

  observeEvent(input$draw1, add_draws(1))
  observeEvent(input$draw10, add_draws(10))
  observeEvent(input$draw100, add_draws(100))
  observeEvent(input$draw1000, add_draws(1000))
  observeEvent(input$reset, {
    # clear simulated draws
    draws(numeric(0))

    # reset UI controls to their defaults (match UI definitions)
    updateSelectizeInput(session, "distType", selected = "Binomial")

    updateSliderInput(session, "bern_p", value = 50)

    updateSliderInput(session, "successRate", value = 50)
    updateNumericInput(session, "trialCount", value = 10)

    updateNumericInput(session, "mean", value = 0)
    updateNumericInput(session, "sd", value = 1)

    updateNumericInput(session, "umin", value = 0)
    updateNumericInput(session, "umax", value = 1)

    updateNumericInput(session, "exp_rate", value = 1)
    updateNumericInput(session, "poisson_lambda", value = 1)

    updateNumericInput(session, "beta_alpha", value = 2)
    updateNumericInput(session, "beta_beta", value = 2)

    updateNumericInput(session, "gamma_shape", value = 2)
    updateNumericInput(session, "gamma_rate", value = 1)
  })

  output$plot <- renderGirafe({
    sim <- draws()

    # ---------- helpers ----------
    empty_plot <- function() girafe(ggplot(), width_svg = 12, height_svg = 8)

    # common theme
    base_theme <- theme_minimal() +
      theme(plot.margin = margin(10, 30, 30, 10))

    # ---------- spec builder ----------
    get_dist_spec <- function(sim) {
      dist <- input$distType

      # ---- BERNOULLI ----
      if (dist == "Bernoulli") {
        p <- input$bern_p / 100
        theory <- data.frame(
          x = 0:1,
          prob = dbinom(0:1, 1, p)
        )

        list(
          type = "discrete",
          theory = theory,
          xlim = c(0, 1),
          ymax = max(theory$prob),
          xlabel = "Outcome (0/1)",
          ylabel = "Probability",
          tooltip_theory = function(df) {
            paste0(
              "Outcome = ",
              df$x,
              "<br>Probability = ",
              round(df$prob, 4)
            )
          }
        )
      } else if (dist == "Binomial") {
        # ---- BINOMIAL ----
        n <- input$trialCount
        p <- input$successRate / 100

        theory <- data.frame(
          x = 0:n,
          prob = dbinom(0:n, n, p)
        )

        list(
          type = "discrete",
          theory = theory,
          xlim = c(0, n),
          ymax = max(theory$prob),
          xlabel = "Number of successes",
          ylabel = "Probability",
          tooltip_theory = function(df) {
            paste0(
              "Success = ",
              df$x,
              " out of ",
              n,
              "<br>Probability = ",
              round(df$prob, 4)
            )
          }
        )
      } else if (dist == "Normal") {
        # ---- NORMAL ----
        mu <- input$mean
        sd <- safe_pos(input$sd)

        x_min <- mu - 4 * sd
        x_max <- mu + 4 * sd

        xs <- seq(x_min, x_max, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dnorm(xs, mu, sd)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(x_min, x_max),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else if (dist == "Uniform") {
        # ---- UNIFORM ----
        a <- input$umin
        b <- input$umax
        if (b <= a) {
          return(NULL)
        }

        xs <- seq(a, b, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dunif(xs, a, b)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(a, b),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density",
          expand_mult = c(0, .85)
        )
      } else if (dist == "Exponential") {
        # ---- EXPONENTIAL ----
        rate <- safe_pos(input$exp_rate)

        x_min <- 0
        x_max <- qexp(.999, rate)

        xs <- seq(x_min, x_max, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dexp(xs, rate)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(x_min, x_max),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else if (dist == "Poisson") {
        # ---- POISSON ----
        lambda <- safe_nonneg(input$poisson_lambda)

        x_max_theory <- ceiling(qpois(.999, lambda))
        x_max_sim <- if (length(sim)) {
          max(ceiling(sim), x_max_theory)
        } else {
          x_max_theory
        }
        xs <- 0:x_max_sim

        theory <- data.frame(
          x = xs,
          prob = dpois(xs, lambda)
        )

        list(
          type = "discrete",
          theory = theory,
          xlim = c(0, x_max_sim),
          ymax = max(theory$prob),
          xlabel = "k",
          ylabel = "Probability",
          tooltip_theory = function(df) {
            paste0("k = ", df$x, "<br>Probability = ", round(df$prob, 4))
          }
        )
      } else if (dist == "Beta") {
        # ---- BETA ----
        a <- safe_pos(input$beta_alpha)
        b <- safe_pos(input$beta_beta)

        xs <- seq(0, 1, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dbeta(xs, a, b)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(0, 1),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else if (dist == "Gamma") {
        # ---- GAMMA ----
        shape <- safe_pos(input$gamma_shape)
        rate <- safe_pos(input$gamma_rate)

        x_min <- 0
        x_max <- qgamma(.999, shape, rate)

        xs <- seq(x_min, x_max, length.out = 400)
        theory <- data.frame(
          x = xs,
          density = dgamma(xs, shape, rate)
        )

        list(
          type = "continuous",
          theory = theory,
          xlim = c(x_min, x_max),
          ymax = max(theory$density),
          xlabel = "Value",
          ylabel = "Density"
        )
      } else {
        NULL
      }
    }

    # ---------- build plot ----------
    spec <- get_dist_spec(sim)
    if (is.null(spec)) {
      return(empty_plot())
    }

    g <- ggplot()

    # ---- simulated layer ----
    if (spec$type == "continuous") {
      if (length(sim) > 0) {
        g <- g +
          geom_histogram_interactive(
            data = data.frame(x = sim),
            aes(
              x = x,
              y = after_stat(density),
              tooltip = paste0("Count: ", after_stat(count)),
              data_id = after_stat(x)
            ),
            bins = 40,
            boundary = spec$xlim[1],
            fill = "steelblue",
            alpha = .6,
            color = "white",
            linewidth = .4
          )
      }

      g <- g +
        geom_line(
          data = spec$theory,
          aes(x = x, y = density),
          linewidth = 1
        )
    } else if (spec$type == "discrete") {
      # sim df
      df_sim <- if (length(sim) == 0) {
        data.frame(x = integer(), prob = numeric(), count = integer())
      } else {
        tab <- table(sim)
        data.frame(
          x = as.integer(names(tab)),
          count = as.integer(tab),
          prob = as.integer(tab) / sum(tab)
        )
      }

      g <- g +
        geom_col_interactive(
          data = df_sim,
          aes(
            x = x,
            y = prob,
            tooltip = paste0(
              "Count: ",
              count,
              " out of ",
              length(sim),
              "<br>Proportion: ",
              round(prob, 4)
            ),
            data_id = x
          ),
          fill = "steelblue",
          width = .8,
          alpha = .6
        ) +
        geom_line(
          data = spec$theory,
          aes(x = x, y = prob),
          linewidth = 1
        ) +
        geom_point_interactive(
          data = spec$theory,
          aes(
            x = x,
            y = prob,
            tooltip = spec$tooltip_theory(spec$theory),
            data_id = paste0("theory_", spec$theory$x)
          ),
          size = 3
        ) +
        scale_x_continuous(
          breaks = scales::breaks_pretty(n = 10, integer = TRUE)
        )
    }

    expand_mult <- spec$expand_mult %||% c(0, .25)

    g <- g +
      coord_cartesian(
        xlim = spec$xlim,
        ylim = c(0, spec$ymax),
        clip = "off"
      ) +
      scale_y_continuous(expand = expansion(mult = expand_mult)) +
      labs(x = spec$xlabel, y = spec$ylabel) +
      base_theme

    girafe(ggobj = g, width_svg = 12, height_svg = 8)
  })

  # compact single-line simulation values, most recent on the left in bold
  output$sim_list <- renderUI({
    sim_vals <- draws()

    # small formatter: integers as integers, others rounded to 2 decimals
    fmt_val <- function(x) {
      if (is.na(x)) {
        return("NA")
      }
      if (!is.numeric(x)) {
        return(as.character(x))
      }
      if (abs(x - round(x)) < 1e-8) {
        as.character(as.integer(round(x)))
      } else {
        sprintf("%.2f", round(x, 2))
      }
    }

    if (length(sim_vals) == 0) {
      return(tags$div(
        tags$div(
          "Simulation Results:",
          style = "font-weight:600; margin-bottom:4px;"
        ),
        tags$div("No simulations yet", style = "font-size:0.9em; color:#666;")
      ))
    }

    max_show <- 100L
    show_vals <- tail(sim_vals, max_show)
    show_vals_rev <- rev(show_vals) # most recent first (left)

    spans <- lapply(seq_along(show_vals_rev), function(i) {
      v <- show_vals_rev[i]
      txt <- fmt_val(v)
      if (i == 1L) {
        tags$span(
          txt,
          style = "font-weight:700; margin-right:10px; white-space:nowrap;"
        )
      } else {
        tags$span(
          txt,
          style = "color:#333; margin-right:10px; white-space:nowrap;"
        )
      }
    })

    tags$div(
      tags$div(
        "Recent simulations:",
        style = "font-weight:600; margin-bottom:4px;"
      ),
      tags$div(
        style = "font-size:0.9em; padding-top:2px; padding-bottom:6px; overflow-x:auto; white-space:nowrap;",
        spans
      )
    )
  })
}

shinyApp(ui, server)
